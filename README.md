# 价格详情 H5 设计交付说明

## 1. 页面范围

本页面运行在 APP WebView 中，只实现策略切换、终端切换、分时价格列表和价格说明；顶部 APP 原生导航不在 H5 内重复实现。

本项目用于确认页面视觉、信息结构和交互效果，不重新定义线上 APP 与 H5 的通信方式、接口字段或数据来源。正式开发应沿用现有线上方案，并将真实数据映射到本页面展示规则。

| 文件 | 内容 |
|---|---|
| `index.html` | 页面结构、表头和价格说明文案 |
| `styles.css` | 响应式布局、列对齐、选中状态和动效 |
| `app.js` | 原型数据、价格排序、策略/终端切换及当前时段定位 |
| `assets/` | 透明背景三倍 PNG 切图 |
| `fonts/` | 数字使用的 D-DIN WOFF2 字体 |

## 2. 四种策略差异

| 策略 | 终端区 | 档位图标 | 价格内容 |
|---|---|---|---|
| 立即充电 | 多终端时显示 | 显示 | 按场站实际提供的价格类型显示 |
| 有序充电 | 不显示 | 显示 | 按场站实际提供的价格类型显示 |
| 经济充放 | 不显示 | 不显示 | 显示充电价与放电价 |
| 立即放电 | 不显示 | 不显示 | 显示放电价 |

- 只有一个可用策略时，整个策略 Tab 隐藏。
- 立即充电只有一个终端时，整个终端区折叠。
- 从立即充电切换到其他策略时，终端区折叠，表头随布局平滑上移。
- 优惠价、黑钻会员价和挂牌价与场站实际价格能力有关，不与充电策略绑定；有什么显示什么，缺少的类型不占位。
- 价格说明中的挂牌价、优惠价和黑钻会员价，跟随当前页面实际展示的价格类型动态显隐。
- 价格说明底部三条提示为公共文案，不随策略切换。

## 3. 核心展示规则

### 价格顺序

- 用户当前实际享受的价格始终放在第一行，并使用红色强调。
- 在可享价格置顶的基础上，其余价格按金额从低到高排列。
- 有多档价格时，最贵的不可享价格位于最下方，并使用灰色弱化。
- 价格名称、价格类型和用户实际享受哪一档，以线上现有业务结果为准，H5 只负责按上述规则展示。

### 当前时段

- 用户首次进入页面时，以动画滚动定位到当前时段。
- 切换策略时直接定位当前时段，不重复播放列表滚动动画。
- 定位只改变页面滚动位置，不改变原有时段顺序。
- 用户主动触摸或滚动时，自动定位立即停止。

### 宽度适配

- 普通手机保持满宽展示。
- 页面最大宽度为 `480px`；平板、折叠屏和横屏超过该宽度后居中显示。
- 吸顶表头、Tab、终端和卡片必须跟随同一个页面容器，不能分别设置不同最大宽度。

## 4. 开发时不要破坏的布局关系

- 策略白色选中块使用位移动画，不能通过显示/隐藏模拟切换。
- 终端区使用高度和透明度折叠，不能直接使用 `display: none`，否则表头会上移得很突兀。
- 表头与价格卡片共用同一套列比例、左内边距和列间距，修改时必须同步检查。
- 当前时段使用内描边，不应改变卡片实际尺寸或造成列表抖动。
- 价格说明中的价格类型随当前实际价格数据显隐，不要按策略写死，也不要在 HTML 中复制多套说明卡片。

## 5. 资源规范

- `assets/` 只保留透明背景三倍 PNG，不保留 SVG 或旧下载资源。
- CSS 按逻辑尺寸展示三倍图，不能使用图片原始像素作为页面尺寸。
- `fonts/` 只保留转换后的 D-DIN WOFF2，不保留原始 OTF。
- 新增图标沿用 `name@3x.png` 命名，并确认透明通道和清晰度。

## 6. 交付前验收

- 在 `280 / 320 / 375 / 430px` 宽度下无横向溢出，时段与三列价格保持对齐。
- 超过 `480px` 后页面居中，不继续横向拉伸。
- 四个策略的终端区、图标和价格内容符合策略差异表。
- 优惠价、黑钻会员价和挂牌价按场站实际数据显示，未提供的类型不出现空白占位。
- 当前可享价格置顶标红，其余价格排序正确，最贵的不可享价格位于最下方。
- Tab 白色滑块平滑移动，终端折叠时表头平滑上移。
- 当前时段唯一高亮；首屏有定位动画，切换策略不重复播放滚动动画。
- 所有三倍图和 D-DIN 字体正常加载，控制台无报错。
