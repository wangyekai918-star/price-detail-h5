01

当前时段滚动触发范围不对，且速度参数没有按交付实现

当前代码把同一个 getLocation() 用在首次进入、切换策略和切换终端三个场景，并统一执行 500ms 线性滚动。这样来回切换时列表会反复滚动，用户已经开始操作时也可能被动画抢走控制权。

重点：滚动动画只能在首次进入页面时播放一次。
修改方式：首次价格数据渲染完成后执行一次带缓动的自动滚动；切换策略时直接定位当前时段，不播放动画；切换终端时保持原来的滚动位置。动画进行中一旦检测到触摸、拖动、滚轮或滚动按键，应立即取消。
滚动参数与实现逻辑
播放时长固定 450ms
触发范围仅首次进入页面播放一次
缓动Ease Out Quart：前快后慢

时长规则：滚动动画统一使用 450ms。

查看完整实现代码 
// 页面生命周期内只允许首批有效价格数据渲染后进入一次
let didPlayInitialScroll = false;
let animationId = 0;

function cancelAutoScroll() {
  if (!animationId) return;
  cancelAnimationFrame(animationId);
  animationId = 0;
}

function getCurrentPeriodTarget(scroller, currentCard) {
  const scrollerTop = scroller.getBoundingClientRect().top;
  const cardTop = currentCard.getBoundingClientRect().top;
  const rawTarget = scroller.scrollTop + cardTop - scrollerTop;
  const maxScrollTop = scroller.scrollHeight - scroller.clientHeight;
  return Math.max(0, Math.min(rawTarget, maxScrollTop));
}

function runInitialCurrentPeriodScroll(scroller, currentCard) {
  if (didPlayInitialScroll || !currentCard) return;
  didPlayInitialScroll = true;

  const start = scroller.scrollTop;
  const target = getCurrentPeriodTarget(scroller, currentCard);
  const distance = target - start;
  const duration = 450;

  if (Math.abs(distance) < 1) return;

  if (matchMedia("(prefers-reduced-motion: reduce)").matches) {
    scroller.scrollTop = target;
    return;
  }

  const startedAt = performance.now();
  const step = (now) => {
    const t = Math.min(1, (now - startedAt) / duration);
    const eased = 1 - Math.pow(1 - t, 4); // Ease Out Quart
    scroller.scrollTop = start + distance * eased;
    if (t < 1) {
      animationId = requestAnimationFrame(step);
    } else {
      animationId = 0;
    }
  };
  animationId = requestAnimationFrame(step);
}

// 首批价格数据渲染完成后调用；双 RAF 避免读取到未稳定的布局位置
function onInitialPriceRendered(scroller) {
  requestAnimationFrame(() => requestAnimationFrame(() => {
    const currentCard = scroller.querySelector("[data-current-period='true']");
    runInitialCurrentPeriodScroll(scroller, currentCard);
  }));
}

// 用户主动操作时立即取消
["touchstart", "pointerdown", "wheel"].forEach((name) => {
  scroller.addEventListener(name, cancelAutoScroll, {
    capture: true,
    passive: true
  });
});
window.addEventListener("keydown", (event) => {
  if (["ArrowUp", "ArrowDown", "PageUp", "PageDown", "Home", "End", " "]
      .includes(event.key)) cancelAutoScroll();
}, true);

// Tab：重新渲染后直接定位，不播放动画
function onStrategyRendered(scroller) {
  const currentCard = scroller.querySelector("[data-current-period='true']");
  if (currentCard) scroller.scrollTop = getCurrentPeriodTarget(scroller, currentCard);
}

// 终端：渲染前保存 scrollTop，渲染后原样恢复
function rerenderTerminal(scroller, renderTerminalPriceList) {
  const previousScrollTop = scroller.scrollTop;
  renderTerminalPriceList();
  requestAnimationFrame(() => { scroller.scrollTop = previousScrollTop; });
}
  • 用双 requestAnimationFrame 等待列表 DOM 和样式稳定后再读取位置。
  • 不要把自动滚动放进通用的“数据刷新完成”回调，否则策略和终端切换都会重复触发。
02

数字字体包与设计交付不一致

当前时间和价格数字的轮廓、笔画明显偏粗，与设计交付的 D-DIN PRO 600 SemiBold 显示效果不一致。

修改方式：替换为设计交付的 D-DIN-PRO-600-SemiBold.woff2 字体包，字重保持 600；同时更新资源版本，确认页面实际加载的是新字体文件。
03

终端标签直接消失，表头上移过于突兀

从“充电价格”切到其他策略时，终端节点会直接卸载，表头瞬间跳到上方，没有形成“终端区域被折叠起来”的感觉。

修改方式：不要先使用 display:none。终端内容先用 160ms 淡出，40ms 后开始收起高度；max-height 与 padding-top 使用 320ms、cubic-bezier(0.22, 0.8, 0.24, 1)。表头保持正常文档流，让它随终端区域收起连续上移。
04

表头与价格列表没有左对齐

表头使用 37% 比例，卡片内部又单独叠加外边距、左 padding、gap 和 calc(37% - 10px)。两套公式在不同屏宽下会产生列起点偏差。

修改方式：表头和卡片外层共用 grid-template-columns: minmax(0,1fr) minmax(0,2fr)；右侧价格区再共同使用三列等分网格。不要分别计算两套宽度。
05

当前时段卡片使用普通 border，内部会缩进 1px

高亮卡多出的 1px 边框参与盒模型，导致它的内部可用空间比普通卡小，时间和价格列坐标会产生轻微变化。

修改方式：去掉真实 border，使用 box-shadow: inset 0 0 0 1px #00ACE5 绘制内描边。这样视觉保持不变，但不会改变卡片内部尺寸和列坐标。
06

策略 Tab 外层白色父容器的圆角会漏出页面灰底

策略 Tab 的外层白色父容器存在圆角，圆角外侧会露出页面灰色背景。

修改方式：去掉外层白色父容器的圆角。
07

策略 Tab 外层白框高度写死，产生多余上下留白

问题不在 Tab 组件本身，而是外面的白色父容器写死了高度，没有紧贴内部 Tab 内容，因此上下出现了额外留白。

修改方式：去掉外层白色父容器写死的 height / min-height 和多余上下 padding，让父容器高度由内容撑开；灰色 Tab 组件自身仍保持 30px 高。
08

表头整体高度偏高

开发页表头高度为 51px，设计稿及参考页为 46px，多出的高度让表头区域偏松，并把下面的价格卡片向下挤。

修改方式：将表头外层总高度调整为 46px，上下 padding 按 8px 设置，并保持文字整体垂直居中；不要继续使用当前上下各 10px 的间距。
09

客服电话号码及格式错误

开发页显示为 4001-300001，号码内容及分组格式均与设计稿不一致。

修改方式：改为 400-130-0001，完整文案为“如对价格展示有疑问，可拨打客服电话400-130-0001。”
10

价格说明与上方时段卡片距离过近

最后一张充电时段卡片与“价格说明”标题之间的留白不足，两块内容贴得太近，层级不清晰。

修改方式：将时段卡片列表与“价格说明”标题之间的垂直间距调整为 16px。
